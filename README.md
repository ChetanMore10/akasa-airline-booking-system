# Akasa Airline Ticket Booking System

A full-stack airline ticket booking system built for learning
Java, Spring Boot, React.js, Docker, GitHub Actions, CI/CD and Kubernetes.

## Backend

- Java
- Spring Boot
- Spring Security
- Hibernate
- JPA
- MySQL
- Maven

## Frontend

- React.js
- JavaScript
- Bootstrap
- Axios

## DevOps

- Git
- GitHub
- Docker
- GitHub Actions
- Kubernetes
